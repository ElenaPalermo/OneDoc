|---|---|
| `listing/<язык>/title.txt` | Название приложения (до 30 символов) |
| `listing/<язык>/short-description.txt` | Краткое описание (до 80 символов) |
| `listing/<язык>/full-description.txt` | Полное описание (до 4000 символов) |

Языки страницы: `ru-RU` (основной), `en-US`, `it-IT`.

## Перед загрузкой заполнить
- В `privacy-policy.md` — `[ИМЯ РАЗРАБОТЧИКА]` / `[DEVELOPER NAME]` / `[NOME DELLO SVILUPPATORE]` и адрес электронной почты для связи (на трёх языках).
- Опубликовать `privacy-policy.md` (например, GitHub Pages) и указать ссылку в Play Console.
- Контактная почта разработчика в Play Console — она видна на странице приложения.

## Скриншоты
Сняты 26.10.2026 на эмуляторе API 37 (release 1.0.0) в интерфейсе своего языка, на демо-документах этого же языка (вымышленная компания, без личных данных):
1. `01_library` — библиотека: PDF с миниатюрой, TXT, CSV, XML, XLSX, DOCX; фильтры «Документы», «Таблицы».
2. `02_pdf` — обложка годового отчёта (PDF), счётчик страниц и ползунок.
3. `03_pdf_search` — поиск в PDF с подсветкой («2026» / «revenue» / «ricavi»).
4. `04_docx` — протокол совещания: заголовки, нумерованный и маркированный списки, жирный и цветной текст.
5. `05_xlsx` — таблица продаж: шапка, даты в формате языка, вкладки листов.
6. `06_theme_dark` — тот же протокол в тёмной теме.
7. `07_xml` — XML с отступами и подсветкой.
8. `08_pdf_toc` — оглавление PDF.

Как переснять: демо-документы делает `make_demo.py` (DOCX/XLSX/CSV/TXT/XML и HTML, из HTML Edge печатает PDF), кадры — сценарий `take2.sh` по adb на экране 1080×2160 (`wm size`) с демо-режимом строки состояния (10:00, полная батарея). Эти скрипты лежали во временной папке сессии и в репозиторий не добавлены.
