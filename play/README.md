# Материалы для Google Play

| Файл | Что это |
|---|---|
| `listing/<язык>/title.txt` | Название приложения (до 30 символов) |
| `listing/<язык>/short-description.txt` | Краткое описание (до 80 символов) |
| `listing/<язык>/full-description.txt` | Полное описание (до 4000 символов) |
| `privacy-policy.md` | Политика конфиденциальности (ru, en, it) — опубликовать по публичному адресу |
| `data-safety.md` | Ответы для Data safety и деклараций «Содержание приложения» |
| `../art/play_icon_512.png` | Значок для Play, 512×512, без прозрачности |

Языки страницы: `ru-RU` (основной), `en-US`, `it-IT`.

## Перед загрузкой заполнить
- В `privacy-policy.md` — `[ИМЯ РАЗРАБОТЧИКА]` / `[DEVELOPER NAME]` / `[NOME DELLO SVILUPPATORE]` и адрес электронной почты для связи (на трёх языках).
- Опубликовать `privacy-policy.md` (например, GitHub Pages) и указать ссылку в Play Console.
- Контактная почта разработчика в Play Console — она видна на странице приложения.

## Ещё нужно подготовить
### Графика
- **Обложка (feature graphic)** — 1024×500, JPEG или PNG без прозрачности. Обязательна.
- **Скриншоты телефона** — от 2 до 8, JPEG или PNG без прозрачности, каждая сторона от 320 до 3840 px, длинная сторона не больше чем в 2 раза длиннее короткой. Для показа в подборках Play нужно минимум 4 скриншота от 1080 px.
  - Экран эмулятора `Medium_Phone_API_37.0` — 1080×2400 (соотношение 2,22), это больше 2:1: скриншоты нужно обрезать, например, до 1080×2160 (убрать строку состояния и полоску навигации) или снять на эмуляторе с экраном 1080×1920.
- **Скриншоты планшета** (7" и 10") — необязательны, но без них приложение хуже показывается на планшетах.

### Предлагаемые скриншоты (на каждом языке страницы — в интерфейсе этого языка)
1. Библиотека: список документов разных типов с миниатюрами PDF.
2. PDF: страница документа, внизу ползунок и номер страницы.
3. Поиск в PDF с подсветкой найденного.
4. DOCX: заголовки, список и таблица.
5. Таблица XLSX: форматированная сетка с закреплённой шапкой и вкладками листов.
6. Темы чтения: тот же документ в тёмной теме или сепии.
7. «Открыть с помощью» из почты или мессенджера с OneDoc в списке.
8. XML с подсветкой.

Документы для скриншотов — без личных данных.
