# Ответы для Play Console: Data safety и раздел «Содержание приложения»

Основание для ответов (проверено 26.10.2026 по release-сборке 1.0.0):
- в итоговом манифесте нет разрешения `INTERNET` и других «опасных» разрешений; единственное — внутреннее `DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` от AndroidX;
- в коде нет сетевых обращений, SDK рекламы, аналитики, отчётов о сбоях и входа в аккаунт;
- доступ к файлам — только через системный выбор (SAF), без `MANAGE_EXTERNAL_STORAGE` и `QUERY_ALL_PACKAGES`;
- Auto Backup включает только настройки (`datastore/settings.preferences_pb`, `app_language.xml`).

Если в приложение добавится сеть, реклама, аналитика или вход — ответы нужно пересмотреть.

## Data safety (Безопасность данных)

| Вопрос | Ответ |
|---|---|
| Does your app collect or share any of the required user data types? / Собирает ли приложение или передаёт какие-либо данные пользователей? | **No / Нет** |

После ответа «Нет» остальные вопросы раздела (шифрование при передаче, запрос на удаление данных, типы данных) не задаются. В сводке страницы будет «No data collected» и «No data shared with third parties».

Перед отправкой стоит сверить в справке Play Console, как Google трактует системный Auto Backup: в копию в аккаунте Google пользователя попадают только настройки, разработчик к ней доступа не имеет.

## Другие декларации раздела «Содержание приложения» (App content)

| Раздел | Ответ |
|---|---|
| Privacy policy / Политика конфиденциальности | Публичный адрес опубликованного `play/privacy-policy.md` (например, GitHub Pages). Обязателен для всех приложений. |
| Ads / Реклама | **No** — приложение не содержит рекламы. |
| App access / Доступ к приложению | **All functionality is available without special access** — входа и подписки нет. |
| Content rating / Возрастной рейтинг | Анкета IARC: категория «Утилиты, продуктивность и прочее» (All Other App Types); на все вопросы о насилии, азартных играх, общении пользователей, покупках, геолокации — **Нет**. Ожидаемый рейтинг — 3+ / Everyone. |
| Target audience / Целевая аудитория | Решает разработчик. Если отметить возраст младше 13 лет, приложение попадает под требования программы Families; проще выбрать **13+** (или 18+). |
| News app / Новостное приложение | **No** |
| Government app / Государственное приложение | **No** |
| Financial features / Финансовые функции | **None** |
| Health / Здоровье | **No** |
| Data deletion / Удаление данных | Не требуется: учётных записей нет, данные не собираются. |
