## Назначение
Нативный офлайн-просмотрщик документов для Android 8.0+ (minSdk 26): PDF, DOCX, DOC, XLSX, XLS, CSV, TXT. Файлы берутся из памяти устройства (через SAF), а также из почты, мессенджеров и файловых менеджеров («Открыть с помощью…» / «Поделиться»). Работает без интернета.

## Архитектура и технологии
- **Язык и UI:** Kotlin (встроенный в AGP 9.4.1, Kotlin 2.2.10), Jetpack Compose (BOM 2026.09.00) + Material 3, Dynamic Colors на Android 12+.
- **Архитектура:** MVVM + Clean. Слои:
  - `domain/` — модели, интерфейсы репозиториев, use cases;
  - `data/` — Room, SAF-хранилище, DataStore, миниатюры, репозитории;
  - `reader/` — движки форматов;
  - `ui/` — экраны.
- **DI:** ручной `di/AppContainer.kt`, экземпляр в `DocFlowApp`; ViewModel создаются через `viewModelFactory`.
- **Навигация:** Navigation Compose 2.10 с маршрутами `@Serializable`.
- **Хранение:**
  - Room 2.8.5 (схема версии 1 в `app/schemas/`): библиотека, «Недавние», позиции чтения, закладки;
  - DataStore Preferences: настройки чтения и библиотеки.
- **Форматы:**
  - PDF — Pdfium (`io.legere:pdfiumandroid`, версия зафиксирована на 2.0.1);
  - DOCX и XLSX — собственные потоковые парсеры (ZIP + свой `XmlScanner` и `XmlPullParser`);
  - DOC и XLS — Apache POI 5.5.1 (HWPF/HSSF из `poi-scratchpad`);
  - CSV и TXT — собственные парсеры с определением кодировки и разделителя.
- **Сборка:** AGP 9.4.1, KSP 2.3.12, compileSdk/targetSdk 37, Java 11. В release R8 включён на весь код; keep-правила лежат в `app/src/main/keepRules/` (`rules.keep`, `poi.keep`, `pdfium.keep`).
- **Объём:** около 13 тыс. строк Kotlin/Java.
  - Основной код (`app/src/main`) — 75 файлов.
  - JVM-тесты — 16 классов, 109 тестов.
  - Инструментальные тесты — 5 файлов: `AppDatabaseTest`, `IncomingIntentTest`, `AssetAttachmentProvider` (Java), `PdfViewerZoomTest`, `SheetViewerZoomTest`.

## Реализовано
0. **Язык интерфейса:** русский, английский, итальянский или «Как в системе» — меню ⋮ главного экрана → «Язык». Выбор сохраняется между перезапусками; на Android 13+ язык меняется и в системных настройках приложения.
1. **Главный экран.**
   - Вкладки «Библиотека» и «Недавние»; от 600 dp ширины — `NavigationRail`.
   - Список или сетка: иконки типов, размер, дата, миниатюры первой страницы PDF (кэш в памяти + JPEG на диске).
   - Мгновенный поиск по имени, фильтр-чипы по типу, сортировка по дате, имени и размеру. Эти настройки хранятся в DataStore.
   - Меню документа: «Поделиться», «Открыть с помощью» (оба системных выбора исключают само приложение), «Переименовать», «Удалить», «Убрать из недавних».
2. **Библиотека через SAF.**
   - Папки (`OpenDocumentTree`, persistable-разрешения) и отдельные файлы (`OpenMultipleDocuments`).
   - Автосканирование при запуске, pull-to-refresh.
   - Без `MANAGE_EXTERNAL_STORAGE`.
3. **Входящие файлы.**
   - Intent-фильтры VIEW и SEND для всех MIME-типов, а также `application/octet-stream` с определением формата по расширению.
   - Если доступ к временному URI нельзя сохранить, файл копируется в `filesDir/incoming/`.
4. **Общий каркас просмотрщика.**
   - Панели скрываются тапом по центру вместе с системными (immersive-режим).
   - Позиция сохраняется автоматически: с задержкой 1 с и сразу при `ON_STOP`.
   - Закладки в боковой панели, темы чтения «Светлая», «Тёмная», «Сепия» и «по системе».
   - Pinch-to-zoom, поворот экрана без потери позиции.
5. **PDF.**
   - Ленивая отрисовка страниц с LRU-кэшем; при зуме видимый фрагмент дорисовывается в полном разрешении.
   - Переход к странице (ползунок или ввод номера), интерактивное оглавление, поиск с подсветкой.
   - PDF с паролем; темы через `ColorMatrix`.
6. **DOCX, DOC, TXT.**
   - Общая модель `FlowDocument` с переносом текста под ширину экрана.
   - Выбор шрифта, размера и межстрочного интервала; картинки, таблицы, оглавление по заголовкам.
   - Pinch-to-zoom меняет размер шрифта.
7. **XLSX, XLS, CSV.**
   - Вкладки листов, сетка с форматированием чисел, дат и процентов, закреплённая шапка.
   - Чёткий зум: после жеста сетка перекладывается в новом размере шрифта.
   - Поиск по ячейкам.
   - Потоковый разбор в бинарный кэш строк (`SheetRowStore`): сетка видна до окончания разбора.
8. **Производительность** (замеры на эмуляторе):
   - PDF 80 МБ / 400 страниц — около 0,1 с;
   - XLSX 80 МБ (1 млн строк) — первые строки за около 0,2 с, полный разбор около 3,7 с в release;
   - на API 26: PDF 80 МБ — 84 мс, XLSX 80 МБ — 171 мс, CSV 100 тыс. строк — 2 с.
9. **Release-сборка** с R8 проверена на запуск: APK около 21 МБ.
10. **Проверка на устройствах.**
    - API 37 (`Medium_Phone_API_37.0`): все экраны, включая ландшафт.
    - API 26 (`Small_Phone`, 720×1280): все форматы, SAF, меню документа, поворот; 10 из 10 инструментальных тестов.

**Цель.** Пользователь выбирает язык интерфейса в приложении: русский, английский или итальянский, а также вариант «Как в системе». Выбор сохраняется между перезапусками. Содержимое документов не переводится.

**Что установлено при анализе кода**
- Все строки интерфейса уже в `res/values/strings.xml`: 113 строк и плюралы, по умолчанию на русском.
  - Захардкоженных пользовательских строк в Kotlin нет.
  - Тексты исключений в `reader/` и `data/` пользователю не показываются: экраны берут сообщения из `messageRes` и `R.string`.
- Строки берутся из контекста Activity (`stringResource`, `LocalContext`, `resources` в `AppNavHost` и `HomeScreen`). После пересоздания Activity они обновятся сами.
- `MainActivity` наследует `ComponentActivity`, тема — `android:Theme.Material.Light.NoActionBar`. AppCompat не подключён.
- Отдельного экрана настроек нет. На главном экране в верхней панели только кнопки (поиск, вид, папки, сортировка), меню ⋮ нет.
- Эти места читают `Locale.getDefault()` или локаль контекста в момент вызова, поэтому подстроятся сами, если обновлять локаль по умолчанию:
  - даты и размеры в `ui/common/DocumentRow.kt`;
  - `CellFormatter`, `XlsxReader`, `XlsReader`;
  - число в `ReaderSettingsSheet`.

**Принятые решения (подтверждены пользователем 24.10.2026)**
- **Без AppCompat:** иначе понадобились бы новая зависимость, `AppCompatActivity` и тема AppCompat.
  - **API 33+:** системный `LocaleManager.setApplicationLocales`. Система сама хранит выбор и пересоздаёт Activity. Язык будет доступен и в системных «Языках приложений» через `androidResources { generateLocaleConfig = true }` + `res/resources.properties` (`unqualifiedResLocale=ru`).
  - **API 26–32:** выбор хранится в `SharedPreferences` (нужен синхронно, DataStore не подходит). `MainActivity.attachBaseContext` подставляет конфигурацию с локалью и вызывает `Locale.setDefault`. После выбора — `recreate()`.
- **Сохранность данных:** при пересоздании сохраняются ViewModel, `rememberSaveable` и стек навигации. Входящий файл повторно не импортируется: в `onCreate` уже есть проверка `savedInstanceState == null`.
- **Варианты в выборе:**
  - «Как в системе» (по умолчанию) — переведён;
  - «Русский», «English», «Italiano» — каждый на своём языке.
- **Не трогаем:**
  - `applicationId` и пакет;
  - intent-фильтры, импорт файлов;
  - парсеры и содержимое документов (нумерация «а, б, в» в DOCX остаётся);
  - темы, Room-схему (миграция не нужна).

**Ответы пользователя на вопросы**
1. **Язык, если в системе не ru, en и не it** — русский, `values/` остаётся как есть.
2. **Логические значения в ячейках** — на языке интерфейса: ИСТИНА/ЛОЖЬ, TRUE/FALSE, VERO/FALSO. Для языков без перевода — русские, как и интерфейс.

## Незавершённые задачи

- **Android 8, корень «Загрузок»:** провайдер не отдаёт имя папки — оно берётся из URI (`LibraryFolder.nameFromTreeUri`).
- **Подготовка к публикации не начата:**

  - название «DocFlow Reader» рабочее;

  - нет ключа подписи release и сборки AAB;
  - нет политики конфиденциальности и описания доступа к данным;
  - `versionCode = 1`, `versionName = "1.0"`.
- **Не всё проверено на API 26:**
  - тёмная тема и сепия;
  - immersive-режим;
  - восстановление позиции после перезапуска приложения;
  - открытие из приложения «Файлы».
- **Baseline Profile** (необязательный пункт шага 9 плана) не сделан.

## Известные ошибки и ограничения
- **Плавность прокрутки во время разбора большого листа.**
  - Кадр около 22 мс на эмуляторе, из них около 16,5 мс — фаза GPU. Ограничение эмулятора, на реальном устройстве не замерялось.
  - Сборщик мусора берёт около 27 % ядра.
- **Версии, которые нельзя поднимать:**
  - Pdfium выше 2.0.1: 2.0.2+ собраны на Kotlin 2.4;
  - плагины `kotlin` (compose/serialization): должны совпадать с Kotlin из AGP. Подсказки lint `NewerVersionAvailable` для них игнорировать.
- **R8:** после обновления AGP или R8 проверить `mapping.txt` — классы не должны менять пакет (иначе `IllegalAccessError`).
- **Размер APK:** нативные библиотеки Pdfium — около 18 МБ на 4 ABI. AAB это исправит: Play раздаст около 5 МБ на устройство.
- **Android 11+:** корень `Download` нельзя выбрать как папку SAF — файлы оттуда добавляются по одному. На экране библиотеки есть подсказка.
- **Android 8:** MediaStore не отдаёт `DISPLAY_NAME`. Имя берётся из `TITLE` и дополняется расширением (`DocumentFormat.fileName`).
- **Инструментальные тесты:** `connectedDebugAndroidTest` удаляет приложение вместе с данными. Ставить через `installDebug installDebugAndroidTest` и запускать через `adb shell am instrument`.
- **POI на Android:** нет `java.awt`. Многосекционные числовые форматы разбирает `CellFormatter`, цвета XLS берутся из `PaletteRecord`.
- **Эмуляторы:** API 37 однажды сломался (DeadSystemException) и потребовал Cold Boot. Фоновый запуск эмулятора был остановлен Claude Code из-за нехватки памяти: эмуляторы лучше запускать из Device Manager.
- **Автоповорот на API 26:** `accelerometer_rotation` оставлен в 0 после проверок.
